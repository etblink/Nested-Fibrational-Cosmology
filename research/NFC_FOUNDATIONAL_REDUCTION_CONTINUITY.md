This file is a living continuity and handoff record for the adversarial foundational re-examination of Nested Fibrational Cosmology (NFC). It exists so that a new research session can resume from the current epistemic state without reconstructing the entire conversation history.

> **Preserve results, not theories.**

> **Frozen NFC canon + later diagnostic research ≠ expanded NFC canon.**

## 3. Foundational adversarial results — controlling summaries

### Result 1 — Book-I observational kernel is largely generic

Frozen Book I builds:

```text
tests → observational equivalence → quotient → refinement → finite stabilization
```

For a finite carrier Ω and selected tests T,

```math
x \sim_T y \iff T(x)=T(y) \quad \forall T\in T.
```

The quotient and finite stabilization follow in ordinary finite partition mathematics.

**Disposition:** `GENERIC_MATHEMATICS`, with canonicity only relative to the selected test language.

---

### Result 2A — PASS / Protected Persistence

The strongest survivor is the factor/congruence condition

```math
\pi\circ E = \bar E\circ\pi.
```

This is necessary if an effective quotient description is claimed to evolve autonomously under a deterministic process.

What does **not** survive is the promotion from this factor condition to a uniquely fundamental backbone/halo ontology.

**Disposition:** `GENERIC_MATHEMATICS` for quotient closure; stronger NFC ontology `NOT_FORCED`.

---

### Result 2B — Persistence Selection

If failure/collapse conditions are `C_i`, the surviving set

```math
\mathcal V = \{h : C_i(h)=0\ \forall i\}
```

is best interpreted as a viability/admissibility kernel.

Bare survival does not select a preferred low-defect state without a dynamics, basin measure, probability kernel, or other selector.

**Disposition:** `GENERIC_VIABILITY_STRUCTURE`.

---

### Result 3 — Finite regime alphabet

Countermodel established:

```text
finite observation at each finite stage
    does not imply
finite total alphabet / globally finite reality.
```

A chain may have finite stagewise quotients while admitting unbounded growth in distinctions or carrier size.

**Disposition:** local/stagewise finiteness valid; global ontological finiteness `NONFORCED`.

---

### Result 4 — Global termination

Controlling distinction:

```text
fixed-carrier finite stabilization ≠ global termination.
```

Book I proves that a monotone chain of partitions of a fixed finite Ω eventually stops splitting. It does not prove that all lawful enlargements, descriptions, or physical novelty terminate globally.

**Disposition:** finite stabilization `VALID + GENERIC`; global termination `REFUTED_STRONG_FORM`.

A successor idea, kept strictly noncanonical, is **LFGO: Locally Finite, Globally Open**.

### Result 10 — Master Inequality / boundary capacity

The counting portion is generic:

If boundary/interface data have at most `K` local states per interface site,

```math
|B(X)| \le K^{|\partial X|}.
```

If the selected observable factors through the interface,

```math
q_X = \Phi_X\circ c_X,
```

then

```math
|O(X)| \le K^{|\partial X|}.
```

The substantive premise is **interface sufficiency**:

```math
\ker c_X \subseteq \ker q_X.
```

This is not implied by mere locality, finite propagation, or finite carrier size.

**Disposition:** counting `GENERIC`; interface sufficiency `ADDITIONAL_HYPOTHESIS / REGIME_CERTIFICATE`.

Neutral survivor: **Finite-Screen Independence Bound**.

### Result 11 — LS-2 / finite interface sufficiency

Locality must not be conflated with boundary sufficiency.

Four distinct concepts were separated:

1. bounded propagation;
2. local detectability;
3. finite stabilization radius;
4. boundary/interface sufficiency.

Explicit finite countermodels allow bounded/local dynamics while retaining interior distinctions invisible to a fixed collar.

The weakest sufficient condition for a chosen observable `q_U` is simply factorization through the collar statistic `c_U`:

```math
q_U = \Phi_U\circ c_U.
```

Equivalently, equal collar data must imply equal chosen outcomes.

Scoped computational collar automata can certify this for one finite packet without establishing global LS-2 for arbitrary admissible regions/regimes.

**Disposition:** LS-2 strongest form `NOT_DERIVED_FROM_LOCALITY_ALONE`; finite-sufficiency formulation `VALID_CONDITIONAL`.

### Result 12 — Observable exhaustion / probe completeness

Controlling distinction:

```text
quotient-visible ≠ physically exhaustive.
```

To promote the NFC quotient to complete physical observability one would need an independently defined physical observable family `O_phys` and a theorem such as

```math
\forall F\in O_{\rm phys},\quad F = \widehat F\circ q_T.
```

No such general frozen theorem is established.

A definition saying “observable = quotient-descending function” yields only definitional internal completeness, not physical completeness.

Candidate successor hypothesis:

**Operational Exhaustion (OE):**

```math
x\sim_T y \Longrightarrow F(x)=F(y)
\quad\forall F\in O_{\rm phys}.
```

**Disposition:** physical observable exhaustion `UNPROVED`.

Different structurally admissible finite test languages can induce different partitions/quotients.

Important distinction:

```text
maximal ≠ maximum.
```

Structural invariance, finite outputs, refinement stabilization, and universal transport do not uniquely select one probe language.

**Disposition:** quotient canonicity `RELATIVE_TO_T`; unique absolute observation language `UNPROVED`.

Successor concepts: **Declared Observation Algebra** and, more strongly, **Dominant Observation Algebra**.
